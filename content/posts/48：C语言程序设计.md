## break && continue

### 习题

1、求素数这个程序只是为了说明`break`和`continue`的用法才这么写的，其实完全可以不用`break`和`continue`，请读者修改一下控制流程，去掉`break`和`continue`而保持功能不变。

2、上一节讲过怎样把`for`循环改写成等价的`while`循环，但也提到如果循环体中有`continue`语句这两种形式就不等价了，想一想为什么不等价了？

因为while的循环继续条件是满足条件，如果不满足条件就是会跳转，而for是遍历所有条件，不满足的可以continue进入下一次循环，而不是直接break

## 数据抽象习题
定义复数的一些计算
```c
#include<stdio.h>
#include<math.h>

struct complex_struct{double x,y;};
/*这里是一些定义*/
double real_part (struct complex_struct z){
    return z.x;
}

double img_part(struct complex_struct z){
    return z.y;
}

double magnitude(struct complex_struct z){
    return sqrt(z.x*z.x+z.y*z.y);
}

double angle (struct complex_struct z){
    return atan2(z.y,z.x);
}

struct complex_struct makefrom(double x,double y){
    struct complex_struct z;
    z.x=x;
    z.y=y;
    return z;
}


struct complex_struct add(complex_struct m,complex_struct n){
    return makefrom(m.x+n.x,m.y+n.y);
}

int main(){
    struct complex_struct m,n,o,p;
    m.x=1;
    m.y=2;
    n.x=3;
    n.y=4;
    double a,b;
    a=magnitude(m);
    b=angle(m);
    printf("magnitude=%f\n",a);
    printf("angle=%f\n",b);
    return 0;
}
```

### break和continue语句

### 习题

1、求素数这个程序只是为了说明`break`和`continue`的用法才这么写的，其实完全可以不用`break`和`continue`，请读者修改一下控制流程，去掉`break`和`continue`而保持功能不变。

![image.png](https://bucket-plusone.oss-cn-wuhan-lr.aliyuncs.com/img/20261104154127600.png)



```c
#include <stdio.h>

int isprime(int n){
    for (int i=2;i<n;i++)
        if (n%i==0) return 0;
    return 1;
}

int main(){
    for (int j=1;j<100;j++)
        if (isprime(j))
            printf("%d \n",j);
    return 0;
}
```
2、上一节讲过怎样把`for`循环改写成等价的`while`循环，但也提到如果循环体中有`continue`语句这两种形式就不等价了，想一想为什么不等价了？


因为for和while里面，for相当于穷举，而while是对于某一个元素的一个判断逻辑。所以用continue可以跳过穷举逻辑，而while所跳过的是一个迭代那样一个元素的那样一个分支的语句
