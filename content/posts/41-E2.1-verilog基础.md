## modules：hierarchy
### module
```verilog
module top_module ( input a, input b, output out );
    mod_a instance1 (a,b,out);
endmodule

```
不只是直接的传递，我们还可以使用对应的引角的名称，这个是被推荐的工业的用法。
```verilog
module top_module ( input a, input b, output out );
    mod_a instance1 (.in1(a),.in2(b),.out(out));
endmodule
```

### 多路选择器
![image.png](https://bucket-plusone.oss-cn-wuhan-lr.aliyuncs.com/img/20261018193202342.png)

```verilog
module top_module ( 
    input clk, 
    input [7:0] d, 
    input [1:0] sel, 
    output [7:0] q 
);
    wire [7:0]w1,w2,w3;
    my_dff8 instace1(.clk(clk),.d(d),.q(w1));
    my_dff8 instace2(.clk(clk),.d(w1),.q(w2));
    my_dff8 instace3(.clk(clk),.d(w2),.q(w3));
    always @(*) begin
        case (sel)
            2'b00:q=d;
            2'b01:q=w1;
            2'b10:q=w2;
            2'b11:q=w3;
        endcase
    end

endmodule
```

这里面学到了几个很有意思，always语句的一些基本的使用的办法，和case语句，这里的case语句还是很有意思的，一开始我写的还是if else。

### 32位全加器

```verilog
module top_module(
    input [31:0] a,
    input [31:0] b,
    output [31:0] sum
);
    wire cout1;
    add16 instance1 (.cin(1'b0),.a(a[15:0]),.b(b[15:0]),.cout(cout1),.sum(sum[15:0]));
    add16 isntance2 (.cin(cout1),.a(a[31:16]),.b(b[31:16]),.cout(),.sum(sum[31:16]));
    
endmodule

```

主要是分线和和线的语法问题
