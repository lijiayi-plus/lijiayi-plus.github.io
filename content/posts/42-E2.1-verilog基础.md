## verilog languages-procedures

### 优先编码器

![image.png](https://bucket-plusone.oss-cn-wuhan-lr.aliyuncs.com/img/20261019143252067.png)
```verilog

module top_module (
    input [3:0] in,
    output reg [1:0] pos  );
    always @(*) begin
        casez(in)
            4'b???1: pos = 2'b00; 
            4'b??1?: pos = 2'b01; 
            4'b?1??: pos = 2'b10; 
            4'b1???: pos = 2'b11; 
            default: pos = 2'b00; 
        endcase
    end
endmodule
```
这里还是有一个很有意思的点，这个是优先编码器，系统会优先识别后面的那个符号，而不是前面的，区别于之前前面的编码器。所以可以看到这里的？和1的交替顺序是和之前相反的。

8位的优先编码器如下：
```verilog
// synthesis verilog_input_version verilog_2001
module top_module (
    input [7:0] in,
    output reg [2:0] pos );
    always @(*) begin
        casez(in)
            8'b???????1 : pos = 3'd0;
            8'b??????10 : pos = 3'd1; 
            8'b?????100 : pos = 3'd2;
            8'b????1000 : pos = 3'd3;
            8'b???10000 : pos = 3'd4;
            8'b??100000 : pos = 3'd5;
            8'b?1000000 : pos = 3'd6;
            8'b10000000 : pos = 3'd7;
            default     : pos = 3'd0;
        endcase
    end
endmodule

```

```verilog
& a[3:0]     // AND: a[3]&a[2]&a[1]&a[0]. Equivalent to (a[3:0] == 4'hf)
| b[3:0]     // OR:  b[3]|b[2]|b[1]|b[0]. Equivalent to (b[3:0] != 4'h0)
^ c[2:0]     // XOR: c[2]^c[1]^c[0]
```
这可以很方便我们使用并且作为效验码

### 翻转一个100位的数

答案是一个比较有意思的，里面使用了$bits(out)这样一个函数
```verilog
module top_module (
	input [99:0] in,
	output reg [99:0] out
);
	
	always @(*) begin
		for (int i=0;i<$bits(out);i++)		// $bits() is a system function that returns the width of a signal.
			out[i] = in[$bits(out)-i-1];	// $bits(out) is 100 because out is 100 bits wide.
	end
	
endmodule

```

### 256to1的选择器：

这里提供了一种很有意思的解法，就是assign语句对于里面的序号可以不用写死，可以直接用assign语句来进行选择：
```verilog
module top_module( 
    input [1023:0] in,
    input [7:0] sel,
    output [3:0] out );
    assign out=in[sel*4+:4];
endmodule

```

### 边缘捕捉器
![image.png](https://bucket-plusone.oss-cn-wuhan-lr.aliyuncs.com/img/20261024144135279.png)
这个题目还是比较有难度的，但是我没借助AI翻译一遍过了哈哈，不错。
```verilog
module top_module (
    input clk,
    input reset,
    input [31:0] in,
    output [31:0] out
);
    reg [31:0]temp;
    integer i;
    always @(posedge clk)begin
        temp<=in;
        if (reset) out<=32'd0;
        else begin
            for (i=0;i<32;i++)begin
                if(temp[i]&&~(in[i])) out[i]<=1'b1;
            end
        end
    end

endmodule

```

让我对于逻辑和判断，位运算有了深入一点的理解哈哈。

### 双边缘触发器

因为posedge和negedge不可以同时使用，所以我们需要各自always最终来一个综合，综合的时候我们运用这个clk信号本身执行一个2选1的选择器。

需要注意的是，posedge出发以后，执行非阻塞赋值的瞬间是在所有的阻塞的运算执行完成以后，一起进行赋值，实际上也就是这个posedge过后一点点时间。

里面还涉及到一个比较重要的事情，就是里面的优先级的概念，一般是外部的使能，reset信号的优先级更加高
