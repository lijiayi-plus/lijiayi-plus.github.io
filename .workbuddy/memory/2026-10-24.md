## 追加：确定"更新博客"的最简命令（已实测）

`git add -n` 预演对比结果：`git add -A` 会纳入 `.workbuddy/memory/2026-10-24.md`；`git add -A -- ':!.workbuddy'` 输出为空，排除生效。

因此给用户的单条发布命令为：

```bash
git add -A -- ':!.workbuddy' && git commit -m "update" && git push
```

备选（一次配置后更短）：在 `.gitignore` 加 `.workbuddy/`，之后用 `git add -A && git commit -m "update" && git push`。用户尚未选择，`.gitignore` 仍未改动。
